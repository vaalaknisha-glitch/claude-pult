# Пульт Claude

Небольшая программа для Windows, через которую ИИ-ассистент (например, Claude) может запускать команды на вашем компьютере — **только после вашего подтверждения**.

![значок](pult.png)

## Как это работает

1. Ассистент кладёт текстовый файл с командой в папку `Загрузки\ClaudePult\zadaniya\`.
2. Пульт (живёт в трее) показывает справа внизу небольшое тёмное окно: что делает команда, из какого чата она пришла, и кнопки **«Выполнить»** / **«Отклонить»**. Текст команды можно раскрыть по клику.
3. Окно не перехватывает фокус — игры и браузер не сворачиваются.
4. Результат (код завершения и вывод) записывается в `Загрузки\ClaudePult\otvety\<имя>.log`, ассистент его читает.

Каждая команда выполняется **только** после нажатия «Выполнить». Команды запускаются с правами обычного пользователя.

## Установка

1. Скачайте репозиторий (зелёная кнопка **Code → Download ZIP**) и распакуйте.
2. Запустите `ustanovit_pult.bat` (двойной клик). Пульт скопируется в `%LOCALAPPDATA%\ClaudePult`, добавится в автозагрузку и запустится.

Удаление: правый клик по значку в трее → «Выход», затем удалить `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\ClaudePult.vbs` и папку `%LOCALAPPDATA%\ClaudePult`.

## Формат задания

Файл `zadaniya\<имя>.txt` в UTF-8:

```
ТРЕД: Название чата
ОПИСАНИЕ: Что делает команда, простыми словами
ПОДРОБНО: (необязательно) детали

команда cmd
ещё команда
```

## Настройки

Клик по значку со щитом в трее: громкость звука (по умолчанию 20%), звук вкл/выкл, уведомление «Готово» после выполнения, показ текста команды сразу, автозапуск с Windows.

Оранжевая точка на значке — команда ждёт ответа.

## Требования

Windows 10/11, встроенный Windows PowerShell 5.1. Ничего устанавливать не нужно.
